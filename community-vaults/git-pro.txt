git reflog -> View all recent actions (The "Undo" button for lost commits)
git checkout - -> Switch back to the previous branch instantly
git commit --amend --no-edit -> Add staged changes to the last commit without changing the message
git reset --soft HEAD~1 -> Undo the last commit but keep your changes staged
git restore --staged <file> -> Unstage a specific file but keep your local changes
git cherry-pick <commit-hash> -> Apply a specific commit from another branch to the current one
git stash pop -> Apply the last stashed changes and remove them from the stash list
git clean -fd -> Interactively remove all untracked files and directories
git branch -D <branch_name> -> Force delete a branch (even if not merged)
git diff --staged -> View changes that are staged for the next commit
git remote prune origin -> Remove local references to branches that were deleted on GitHub/GitLab
git shortlog -sn -> View contribution stats (Who committed how many times)
