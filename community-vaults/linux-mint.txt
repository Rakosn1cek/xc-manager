sudo apt update -> Synchronise the local package index with the remote repositories
sudo apt upgrade -> Install the newest versions of all currently installed packages
sudo mintupdate-cli upgrade -> Run the Mint Update Manager via the terminal to apply updates
sudo apt install {{package}} -> Install a specific package and its required dependencies
sudo apt remove {{package}} -> Uninstall a package while leaving its configuration files intact
sudo apt purge {{package}} -> Completely remove a package along with all configuration files
sudo apt autoremove -> Remove packages that were automatically installed and are no longer required
apt show {{package}} -> Display detailed information including version and description for a package
apt list --installed -> List every package currently installed on the system
apt search {{pattern}} -> Search for a specific keyword in the package descriptions
sudo add-apt-repository ppa:{{user/repo}} -> Add a Personal Package Archive (PPA) to the system sources
sudo add-apt-repository --remove ppa:{{user/repo}} -> Remove a previously added PPA from the system
sudo mint-meta-cinnamon -> Install the full meta-package for the Cinnamon desktop environment
sudo mint-meta-mate -> Install the full meta-package for the MATE desktop environment
sudo mint-meta-xfce -> Install the full meta-package for the XFCE desktop environment
mintinstall -> Launch the graphical Software Manager from the terminal
sudo timeshift --create --comments "{{snapshot_name}}" -> Create a system restore point using Timeshift
sudo timeshift --restore -> Launch the interactive wizard to restore a system snapshot
/usr/lib/linuxmint/mintsystem/mint-adjust.py -> Run the Mint-specific system adjustment script
mint-fortune -> Display the Mint-specific quotes or tips in the terminal
sudo ufw enable -> Turn on the Uncomplicated Firewall for basic system protection
sudo ufw allow {{port}} -> Open a specific port through the firewall
gufw -> Launch the graphical user interface for the firewall settings
sudo timeshift --list -> List all available system snapshots created by Timeshift
sudo apt-mark hold {{package}} -> Prevent a specific package from being automatically updated
sudo apt-mark unhold {{package}} -> Allow a previously held package to be updated again
sudo dpkg -i {{path/to/package.deb}} -> Install a local Debian package file manually
dpkg -L {{package}} -> List every file installed on the system by a specific package
sudo dpkg-reconfigure {{package}} -> Re-run the post-installation configuration for a package
sudo apt update && apt list --upgradable -> Refresh the index and show exactly which packages can be updated
sudo apt clean -> Clear out the local repository of retrieved package files
sudo journalctl -xe -> Open the system journal to the end with explanatory help text
sudo systemctl restart {{service}} -> Stop and then start a systemd service immediately
systemctl is-active {{service}} -> Check if a specific service is currently running
sudo adduser {{username}} -> Create a new user account with interactive prompts
sudo usermod -aG sudo {{user}} -> Grant a specific user administrative privileges
cat /etc/linuxmint/info -> Display detailed information about the Mint release version
sudo update-grub -> Automatically find kernels and update the GRUB bootloader menu
lsb_release -a -> Display detailed information about the Linux distribution
sudo apt-file search {{filename}} -> Find which package contains a specific file or binary
sudo netstat -plnt -> List all processes currently listening on network ports
sudo tail -f /var/log/auth.log -> Monitor system authentication and login attempts in real-time
sudo fdisk -l -> List all partitions and storage devices attached to the system
sudo blkid -> Show the UUIDs and filesystem types for all disk partitions
sudo mount -a -> Mount all filesystems listed in the /etc/fstab file
sudo sysctl -p -> Apply changes to the kernel parameters without a reboot
sudo apt install -f -> Attempt to fix a system with broken or missing dependencies
nmcli dev wifi rescan -> Force the network manager to look for new Wi-Fi signals
grep -r --include="*.list" "^deb" /etc/apt/ -> List every active software source URL
sudo apt-cache policy {{package}} -> Check the installation priority and source of a package
