# --- GIT OPERATIONS ---
git commit -m "{{message}}" -> Commit changes with a custom message
git push origin {{branch}} -> Push current work to a specific remote branch
git checkout -b {{new_feature}} -> Create and switch to a new branch
git tag -a v{{version}} -m "{{release_notes}}" -> Create a signed release tag
git clone {{url}} -> Clone a repository into a new directory
git pull origin {{branch}} -> Fetch from and integrate with another repository or a local branch
git branch -d {{branch_name}} -> Delete a local branch that has been merged
git stash push -m "{{label}}" -> Stash current changes with a descriptive label
git remote add origin {{url}} -> Connect the local repository to a remote server
git checkout {{commit_hash}} -> Switch the working tree to a specific point in history
git reset --soft HEAD~1 -> Undo the last commit while keeping changes staged
git rebase -i HEAD~{{count}} -> Start an interactive rebase for the last N commits
git ammend --no-edit -> Add staged changes to the previous commit without changing the message

docker volume create {{volume_name}} -> Create a persistent data volume
docker network create {{network_name}} -> Create a custom bridge network for containers
docker inspect {{id}} -> View detailed metadata of a container or image in JSON format
docker system prune -a -> Remove all unused containers, networks, and images
docker-compose up -d -> Start a multi-container application in the background
docker-compose down --volumes -> Stop and remove containers, networks, and associated volumes
docker stats -> View real-time resource usage statistics for all containers
